# VERA

VERA is a modern streetwear ecommerce storefront built with React and Vite, inspired by contemporary fashion brands such as Escape Closet and The Last Ape.

The project was developed as a portfolio-quality frontend application focused on premium UI design, responsive layouts, scalable React architecture, and realistic ecommerce interactions.

## Features

- Dynamic product pages using React Router
- Shopping cart functionality
- Currency conversion using a live exchange rate API
- Responsive product grid layouts
- Reusable component architecture
- Context API state management
- Minimal editorial-inspired UI
- Product data rendered from local JSON
- Animated cart interactions and hover states

## Tech Stack

- React
- Vite
- React Router
- Context API
- CSS Modules
- JavaScript
- Exchange Rate API

## Project Goals

The goal of this project is to simulate a modern fashion ecommerce experience while demonstrating practical frontend development skills including:

- Component-driven architecture
- API integration
- State management
- Client-side routing
- Responsive UI engineering
- Ecommerce UX patterns

## Inspiration

This project draws inspiration from modern streetwear and fashion storefronts, particularly brands that use strong typography, minimal layouts, and editorial-style product presentation.
